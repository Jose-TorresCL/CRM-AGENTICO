# CRM Operativo para Revestimiento de Piscinas

Sistema web para gestionar el ciclo completo de una empresa de revestimiento de piscinas:
desde la consulta inicial del cliente hasta el pago final de la obra.

## Documentos

| Documento | Propósito | Audiencia |
|---|---|---|
| [01-negocio.md](./01-negocio.md) | Contexto del negocio, problemas y objetivos | Producto, desarrollo |
| [02-mvp.md](./02-mvp.md) | Alcance mínimo, entidades y reglas esenciales | Producto, desarrollo |
| [03-brd.md](./03-brd.md) | Requisitos de negocio formales | Producto, QA, desarrollo |
| [04-arquitectura.md](./04-arquitectura.md) | Arquitectura técnica y decisiones | Desarrollo |
| [05-roadmap.md](./05-roadmap.md) | Plan de construcción por fases | Producto, desarrollo |

## Regla de uso

- `01-negocio.md`: explica **por qué** existe el sistema.
- `02-mvp.md`: define **qué es indispensable** en la primera versión.
- `03-brd.md`: define **qué debe hacer el sistema**.
- `04-arquitectura.md`: define **cómo se construye**.
- `05-roadmap.md`: define **en qué orden** se construye.

## Fuente de verdad

Si existe conflicto entre documentos:

1. Este índice define la estructura.
2. `02-mvp.md` define el alcance aprobado.
3. `03-brd.md` define los requisitos detallados.
4. `04-arquitectura.md` define las decisiones técnicas.
5. `05-roadmap.md` define la secuencia de implementación.

Ninguna funcionalidad nueva puede incorporarse sin actualizar primero el MVP o el BRD.
